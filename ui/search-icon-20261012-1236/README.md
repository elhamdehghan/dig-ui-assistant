# آیکون سرچ

## درباره این قطعه
آیکون سرچ (جستجو) یک نماد ساده و شناخته‌شده برای رابط‌های جستجو است. این آیکون در نوار جستجو، دکمه‌های جستجو و فیلدهای ورودی استفاده می‌شود.

## کامپوننت انتخاب‌شده
آیکون **Search** از Digcheh (سبک Linear) — یک آیکون ساده و تمیز برای نمایش عملکرد جستجو در رابط‌های کاربری.

## آیکون انتخاب‌شده
آیکون **search** از Digcheh — شامل یک دایره (نمایانگر عدسی) و یک خط (نمایانگر دسته) است. این طراحی استاندارد و شناخته‌شده است.

## نصب
```bash
npx digdesign@latest init
```
