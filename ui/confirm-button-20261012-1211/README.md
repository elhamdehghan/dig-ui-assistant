# دکمهٔ تأیید

## درباره این قطعه
دکمهٔ ساده‌ای برای تأیید و تصدیق اقدامات کاربر. رنگ سبز (success) نشان‌دهندهٔ موفقیت و تأیید است و در فرم‌ها، دیالوگ‌ها و صفحات تأیید استفاده می‌شود.

## کامپوننت انتخاب‌شده
**Button** — دکمهٔ پایه‌ای Dig که با پراپ `color="success"` رنگ سبز می‌گیرد و برای تأیید مناسب است.

## آیکون انتخاب‌شده
آیکونی لازم نبود — درخواست صرفاً برای دکمهٔ ساده‌ای با متن بود و Digcheh فراخوانی نشد.

## نصب
```bash
npx digdesign@latest init
npx digdesign@latest add button
```

## نحوه استفاده
```tsx
import { Button } from "@/components/ui/button";

<Button color="success">تأیید</Button>
```
