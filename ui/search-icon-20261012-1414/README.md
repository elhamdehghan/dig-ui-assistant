# آیکون سرچ

## درباره این قطعه
آیکون سرچ (جستجو) از کتابخانه دیگچه است. برای نمایش عملکرد جستجو در رابط‌های کاربری استفاده می‌شود.

## مسیر انتخاب‌شده
**ICON-ONLY** — کاربر فقط آیکون خواسته بود. دیگچه برای جستجو استفاده شد.

## کامپوننت انتخاب‌شده
کامپوننتی لازم نبود — این یک آیکون تنهایی است.

## آیکون انتخاب‌شده
**Search** (دیگچه) — آیکون سرچ استاندارد با سبک Linear برای رابط‌های کاربری.

## نصب
نیازی به نصب نیست؛ فایل را در پروژه کپی کنید.

## نحوه استفاده
```tsx
import SearchIcon from './SearchIcon';

export default function App() {
  return (
    <button aria-label="جستجو">
      <SearchIcon size={24} />
    </button>
  );
}
```
