# آیکون سرچ

## درباره این قطعه
آیکون سرچ (جستجو) یک نماد بصری ساده برای نشان دادن عملکرد جستجو و کشف محتوا در رابط‌های کاربری است. این آیکون در نوار جستجو، دکمه‌های جستجو و فیلترها استفاده می‌شود.

## مسیر انتخاب‌شده
**ICON-ONLY** — کاربر فقط آیکون خواست، بنابراین تنها Digcheh استفاده شد.

## کامپوننت انتخاب‌شده
کامپوننتی لازم نبود — این یک آیکون خالص است و نیازی به کامپوننت‌های Dig نیست.

## آیکون انتخاب‌شده
**Search** (Linear) — آیکون سرچ استاندارد از کتابخانه Digcheh، مناسب برای تمام رابط‌های جستجو.

## نصب
نیازی به نصب نیست؛ فایل `SearchIcon.tsx` را در پروژه کپی کنید.

## نحوه استفاده
```tsx
import SearchIcon from '@/components/SearchIcon';

// اندازه پیش‌فرض (24px)
<SearchIcon />

// اندازه‌های مختلف
<SearchIcon size="sm" /> {/* 16px */}
<SearchIcon size="md" /> {/* 24px */}
<SearchIcon size="lg" /> {/* 32px */}

// با کلاس‌های Tailwind
<SearchIcon className="text-primary" />
```
