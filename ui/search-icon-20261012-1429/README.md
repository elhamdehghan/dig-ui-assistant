# آیکون سرچ

## درباره این قطعه
آیکون سرچ (جستجو) یک نماد استاندارد برای نشان‌دادن عملکرد جستجو در رابط‌های کاربری است. این آیکون در نوار جستجو، دکمه‌های جستجو و فیلدهای ورودی استفاده می‌شود.

## مسیر انتخاب‌شده
**ICON-ONLY** — کاربر فقط آیکون خواست. تنها Digcheh استفاده شد (search_icons، get_icon_svg).

## کامپوننت انتخاب‌شده
کامپوننتی لازم نبود — درخواست صرفاً برای آیکون بود.

## آیکون انتخاب‌شده
**Search** (Linear) — آیکون استاندارد سرچ از کتابخانه Digcheh، با دایره و خط مورب برای نمایش عدسی بزرگنمایی.

## نصب
نیازی به نصب نیست؛ فایل را در پروژه کپی کنید.

## نحوه استفاده
```tsx
import SearchIcon from './SearchIcon';

// استفاده ساده
<SearchIcon />

// در دکمه
<button className="text-primary">
  <SearchIcon />
</button>

// تغییر سایز
<div className="w-6 h-6 text-secondary">
  <SearchIcon />
</div>
```
